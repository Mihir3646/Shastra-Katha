# Music

`bed.mp3`, `pad.mp3` and `chimes.mp3` were generated by `tools/make-music.py`.
They are synthesised from scratch — no samples, no loops from a library — so
they are yours to use and monetise with no attribution and no content-ID risk.

Regenerate or make variants:

```bash
npm run music -- --style tanpura --key C# --minutes 2 --out assets/music/bed.wav
npm run music -- --style pad     --key D  --minutes 2 --out assets/music/pad.wav
npm run music -- --style chimes  --key G  --minutes 2 --out assets/music/chimes.wav
```

`--key` takes any note name (`C`, `C#`, `Db`, … `B`). Pick one that sits away
from the narrator's pitch so the two do not fight; for a male narrator, keys
around C#–E work well.

## Using someone else's track instead

Point `music.file` in the episode at any file. If you go outside this folder,
check the licence covers monetised video:

- **Pixabay Music**, **YouTube Audio Library** — free, no attribution required.
- **Free Music Archive**, **Incompetech** — mostly CC-BY: free, but you must
  credit the artist in the video description.
- Anything labelled **CC-BY-NC** cannot be used on a monetised channel.
